// turbo-all

This workflow enables automatic execution of all commands. When this workflow is active, Antigravity will auto-run commands without requiring manual approval.

## Usage

This workflow applies globally when referenced. All terminal commands will execute automatically.

## Common Auto-Run Tasks

1. List directory contents
2. View file contents
3. Run development servers
4. Install dependencies
5. Run tests
6. Build projects
7. Git operations
